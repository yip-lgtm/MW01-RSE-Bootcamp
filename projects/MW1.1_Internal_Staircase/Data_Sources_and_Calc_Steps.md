## 二、荷載計算逐步 / Loading Calculation Step by Step

### Step L1 — 寫入材料（來源 1–6）

| 動作 | 內容 |
|------|------|
| 輸入 | S355、7850、E=205000、py=355、焊縫250、玻璃80 |
| 輸出 | 設計數據表 |
| 來源 | CoP Steel 2011、CoP Glass 2018 |

### Step L2 — 寫入幾何（來源 12–14）

| 動作 | 內容 |
|------|------|
| 輸入 | L=1400, a=175, b=230, c=420；平台 900/1685、1200/2000 |
| 計算 | 平均踏面 = (230+420)/2 = **325 mm** |
| 計算 | 每級面積 ≈ 1.40 × 0.325 = **0.455 m²** |
| 來源 | WC025A 圖則 |

### Step L3 — 寫入活荷載（來源 7–10）

| 動作 | 內容 |
|------|------|
| 輸入 | 3.0 kPa；0.75 kN/m；1.0 kPa；0.5 kN |
| 引用 | **Table 3.13** Protective barriers |
| 來源 | CoP Dead & Imposed Loads 2011 |

### Step L4 — 踏步恆載

| 步驟 | 公式／數值 | 結果 |
|------|------------|------|
| 鋼板 15 mm | 0.015 × 77 kN/m³ | 1.16 kPa |
| 面層（假設） | — | 0.50 kPa |
| 面荷載合計 | 1.16 + 0.50 | **1.66 kPa** |
| 每級恆載 | 1.66 × 0.455 | **≈ 0.76 kN** |
| 來源 | 密度→CoP；厚度→圖則 |

### Step L5 — 平台恆載

| 平台 | 面積（估） | 計算 | 結果 |
|------|------------|------|------|
| 中間 | ≈ 1.3 m² | 1.66 × 1.3 | **≈ 2.2 kN** |
| 頂部 | ≈ 2.0 m² | 1.66 × 2.0 | **≈ 3.3 kN** |
| 來源 | 幾何估；精確以 SAP／圖為準 |

### Step L6 — 欄杆荷載

| 類型 | 特徵值 | 應用 |
|------|--------|------|
| 線荷載 | 0.75 kN/m @ 1.1 m | 傳至 C1 / MB1 |
| UDL | 1.0 kPa | 欄杆高度範圍 |
| 集中 | 0.5 kN | 最不利點 |
| 來源 | Table 3.13 |

### Step L7 — 荷載組合

| 步驟 | 公式 | 結果 |
|------|------|------|
| 設計面荷載 | \(W_d = 1.4\times1.66 + 1.6\times3.0\) | **7.12 kPa** |
| 來源 | 組合規則：CoP Steel 慣用；Gk/Qk：本節上表 |

### Step L8 — 荷載總表（報告用）

| Item | DL | LL | Design |
|------|----|----|--------|
| Step/landing surface | 1.66 kPa | 3.0 kPa | **7.12 kPa** |
| Barrier line | — | 0.75 kN/m | 按組合 |
| Barrier UDL / point | — | 1.0 kPa / 0.5 kN | 包絡檢核 |

## 四、一條線串起來（從源到結論）

```
CoP + 圖則 + SAP
        ↓
L1 材料 → L2 幾何 → L3 活載
        ↓
L4 踏步DL → L5 平台DL → L6 欄杆
        ↓
L7 組合 → 7.12 kPa
        ↓
M2 截面 + M3 內力(SAP)
        ↓
M4 利用率 0.87 / 0.81 / 0.09 → 全 OK
        ↓
報告第 4、6 章正式表
```
